# Submission materials

This directory records the public documents prepared for the V11.2 author edition. The [Article](../article/Article.pdf), [preprint](../preprint/Preprint.pdf), [Supplementary Information](../supplement/SupplementaryInformation.pdf), [figures and source tables](../figures/), and [data and code archive](../reproducibility/Data_and_code.zip) are available individually.

| File | Contents |
| --- | --- |
| [Nature_manuscript_source.zip](Nature_manuscript_source.zip) | Current Article and supplement LaTeX sources, the five main figures and the supplementary figure, arranged for compilation. |
| [Preprint_source.zip](Preprint_source.zip) | The preprint entry point, shared Article sources, supplement and the required figure PDFs. |
| [Form_Responses.pdf](forms/Form_Responses.pdf) | The author's six-page reporting summary and software-checklist responses, readable in standard PDF viewers. |
| [Nature_Reporting_Summary.pdf](forms/Nature_Reporting_Summary.pdf) | The reporting form in its original XFA format. |
| [Nature_Software_Checklist.pdf](forms/Nature_Software_Checklist.pdf) | The software checklist in its original XFA format. |
| [Submission_metadata.md](Submission_metadata.md) | Title, authorship, abstract, preprint history, data and code information prepared for submission. |
| [Reproducibility.md](Reproducibility.md) | Original guide accompanying the scientific data and code package. |

The XFA PDFs use interactive publisher templates. A browser may display a “Please wait” page. [Form_Responses.pdf](forms/Form_Responses.pdf) gives the readable author responses. The [adapter files](../adapters/) and [release downloads](../RELEASE_ASSETS.md) complete the software materials.
