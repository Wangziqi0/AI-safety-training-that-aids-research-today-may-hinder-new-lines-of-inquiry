Replace “for every real \(A\ge 8\)” with **“for every real \(A\ge 10\).”** The starting scale \(10\) is sharp. Within the draft’s original domain, \(A=8\) also works, and every \(8<A<10\) fails.

The positive multiples of four are congruent to \(0\), \(4\), or \(8\) modulo \(12\). Only the last class is congruent to \(2\) modulo \(6\), so the common ranks are \(8,20,32,\ldots\). A rank \(m\) serves both readers exactly when \(A\in[m/2,m]\). The first rank therefore covers \([4,8]\), and the second covers \([10,20]\). For every common rank \(m\ge20\), the next rank \(m+12\) begins covering scales at \((m+12)/2\le m\). These intervals overlap and extend without bound, so the exact feasible set is \([4,8]\cup[10,\infty)\).
